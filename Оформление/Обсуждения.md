# Обсуждения VK

Создай такие темы.

## 1. Вопросы по подключению

Описание:

```text
Тема для вопросов по первому подключению Integra CM.

Пишите сюда, если не получается:
• добавить бота в беседу;
• открыть панель;
• подключить беседу командой /connect;
• разобраться с owner-токеном;
• понять, какие права нужны боту.

В заявке укажите:
1. VK ID владельца.
2. Ссылку на беседу или chat id, если есть.
3. Что именно не получилось.
4. Скрин ошибки, если она есть.
```

## 2. Баги и ошибки

Описание:

```text
Нашли ошибку в боте или панели — пишите сюда.

Чтобы мы быстрее разобрались, приложите:
• что делали перед ошибкой;
• какая команда или раздел панели не сработали;
• пример сообщения/команды;
• скриншот;
• примерное время ошибки.

Не публикуйте токены, секретные ключи и приватные данные.
```
